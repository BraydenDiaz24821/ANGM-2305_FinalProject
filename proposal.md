## Description
With Pygame, I want to create my own version of the hit mobile game, Flappy Bird. 

## Features
- A TBD player object (plane, spaceship, etc)
	- With toggled gravity and a stationary position, its up movement could be controlled with the 'W' key.
- Moving obstacles
	- With an infinity loop of sorts, they could be spawned at random and be programmed to slide across the screen's X-axis. 
- Original Artwork
	- Instead of relying on 3rd party libraries, all visual assets (player object, moving obstacles, etc) could be handrawn.

## Challenges
- Implementing gravity into the game.
- Animating the player object if possible. 
- Programming the moving obstacles.

## Outcomes
Ideal Outcome:
- I would like my game to have the same level of functionality as its source material. 

Minimal Viable Outcome:
- If I don't have the time to draw my original assets, I would like to at least have the game's full program completed by the deadline.
