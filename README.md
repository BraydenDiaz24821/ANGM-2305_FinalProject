## About
For my final project in ANGM-2305, I wanted to create a personal take on the classic mobile game, Flappy Bird. Being a word play on the Firefox web browser, the name “FlyerFox” came to fruition during brainstorming. While playing the game, your job is to help a little fox dude evade an endless stream of fire walls without crashing.

During FlyerFox’s development, Coding With Russ’s Flappy Bird playlist (videos 1-4) was used as a foundation. However, I ensured that I made sufficient changes to meet the final project’s criteria for format and originality. To start off, all the visual assets seen in FlyerFox were digitally drawn by me (via Autodesk Sketchbook software). As someone who loves to dabble in 2D art, it felt unorthodox to use third-party libraries. Furthermore, when it came to coding, I added a number of personal touches. These include the intro/game over sessions, player spawn point, screen size, keyboard controls, and overall speed of gameplay. Lastly, when it came to formatting, I attempted to reorganize the playlist’s code to run with a main function.

Overall, getting to work on this project was a great experience!
